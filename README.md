# NexTech IT Group Portfolio

**Turning Ideas Into Digital Solutions.**

## About the Project

The **NexTech IT Group Portfolio** is a group portfolio website developed to showcase the skills, capabilities, projects, and contributions of our team. It serves as a platform where visitors can learn more about our members, explore our developed systems, and discover our interests and technical knowledge in the field of Information Technology.

The website highlights our teamwork, creativity, and commitment to developing technology-driven solutions through academic projects and collaborative experiences.

## Project Objectives

- Introduce the NexTech IT Group and its members.
- Showcase the technical skills and educational backgrounds of each member.
- Present our developed projects and their functionalities.
- Provide information about our technologies and tools.
- Establish an online portfolio that represents our team's capabilities and achievements.

## Website Features

- **Homepage** – Introduces NexTech IT Group and provides an overview of the portfolio.
- **About Us** – Presents the group's background, mission, vision, and core values.
- **Team Profiles** – Displays the three members, their roles, introductions, technical skills, and individual contributions.
- **Projects Showcase** – Features our developed systems with their overviews, problems addressed, and main features.
- **Technologies and Skills** – Highlights the programming languages, tools, and technologies used by the team.
- **Contact Section** – Provides information for visitors who want to connect with the group.
- **Responsive Design** – Allows the website to adapt to different screen sizes and devices.

## Featured Projects

Our portfolio showcases the following projects:

1. **Multi-Branch Coffee Shop System with Inventory Tracking and Sales Monitoring** – A centralized system designed to manage coffee shop operations, inventory, and sales across multiple branches.
2. **Hotel Management System** – A system designed to organize hotel operations, including room management and reservations.
3. **IoT-Based Earthquake Alarm System** – An IoT-based project that detects ground vibrations during an earthquake and automatically triggers an alarm to alert nearby individuals.
4. **Computer Repair Booking System** – A system designed to organize computer repair service requests, appointments, and repair records.

## Development Environment

To run the project locally, the following tools are required:

- XAMPP
- WordPress
- Visual Studio Code
- Web browser

### Installation Guide

1. Install and run XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Install WordPress in the local server directory.
4. Clone or copy the NexTech Portfolio theme into the WordPress themes directory:

   `wp-content/themes/nextech-portfolio/`

5. Open the WordPress dashboard.
6. Navigate to **Appearance → Themes**.
7. Activate **NexTech Portfolio**.
8. Open the website through your local WordPress URL.
